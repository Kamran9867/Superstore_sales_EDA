Superstore Sales Analysis – EDA

Project Overview

This project performs Exploratory Data Analysis (EDA) on Superstore sales data using Python to identify sales trends and business insights.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Analysis Performed

- Data inspection and cleaning
- Missing value and duplicate checks
- Sales and profit analysis
- Exploratory data analysis
- Data visualization

Project Files

- "Superstore_sales_EDA.ipynb" – Jupyter Notebook containing the analysis and visualizations.
- Dataset file – Used for the analysis, if included in this repository.

Key Findings

Key findings will be documented based on the actual analysis and visualizations in the notebook.

How to Run

1. Download this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook.
4. Run the cells in order.
